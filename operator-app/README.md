# Operator app

The app tow operators use to sign up, upload their license and insurance, and switch to Available so nearby drivers can find them. Built with Expo (React Native), Android first.

Everything about it is in the main [README](../README.md):

- **How to run it:** "Run it → The operator app" (Android emulator setup on a Mac, and a quick iPhone test with Expo Go).
- **How it works, file by file:** "The operator app, explained."
- **Why it's built this way:** "Why these choices."

Quick commands:

```bash
npm install
npm test          # logic tests, no phone needed
npm run android   # build and install the development build on a running Android emulator
npm start         # after the first build: start the dev server while you edit JavaScript
```

Before it can run, copy `.env.example` to `.env` and add your Supabase URL and publishable key.

The `android/` and `ios/` folders are generated by `npm run android` / `npm run ios` and are not committed. Native settings live in `app.json` instead.
